## 本包自含的并行/迁移契约

本包遵守以下在WP24 G0实现并冻结、WP23实现执行器的接口；G0/G1未验收前不得启动依赖它的业务。域不自行改公共类型/注册表，也不import同波尚不存在的模块。

```ts
type ColumnSpec = {
  name: string; type: "TEXT" | "INTEGER"; nullable: boolean;
  default?: { kind: "value"; value: string | number | null }
          | { kind: "currentTimestamp" };
  minimum?: number; oneOf?: readonly (string | number)[];
};
type ForeignKeySpec = {
  columns: readonly string[]; table: string; referencedColumns: readonly string[];
};
type AdditiveOperation =
  | { kind: "createTable"; table: string; columns: readonly ColumnSpec[];
      primaryKey?: readonly string[]; unique?: readonly (readonly string[])[];
      foreignKeys?: readonly ForeignKeySpec[] }
  | { kind: "addColumn"; table: string; column: ColumnSpec }
  | { kind: "createIndex"; table: string; name: string;
      columns: readonly string[]; unique?: boolean };
type Migration = { id: string; checksum: string; operations: readonly AdditiveOperation[] };
// 仅执行器内部接收DatabaseSync；迁移贡献者仅提交上述结构化数据。
function applyMigrations(db: DatabaseSync, items: readonly Migration[]):
  { applied: string[]; skipped: string[] };
```

只接受严格普通JSON数据和精确白名单键；拒绝任何up函数、SQL/raw/exec/prepare、未知操作、未知键、函数值及非法标识符。渲染器由WP23内部产生SQL，列类型/默认值/约束为受限结构，不靠易绕SQL字符串黑名单。原表不重建，未知历史状态保留；addColumn不得使旧行失效。失败整批回滚、账本不残留。伪装DDL/DML操作、非标默认表达式、未知键须在真实合成库执行时拒绝并证明旧行未变；SQL样式默认文本只能安全编码为字面量，测试证明不会执行。数字默认值必须是安全整数，CURRENT_TIMESTAMP只允许明确的kind，禁止任意函数/表达式。
