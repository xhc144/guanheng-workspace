# WP-18 验收说明

本包只覆盖 `company/投标方案生成服务/方案生成服务/` 的缺母版降级与隔离测试，不替代主线、真实付款、真实客户母版或线上门户验收。

## 可重复命令

| 实际 cwd（相对仓库根） | 命令 | 作用 |
| --- | --- | --- |
| `company/投标方案生成服务/方案生成服务/` | `npm install --package-lock=false` | 按任务原命令安装现有依赖，不改 package/lock |
| 同上 | `npm test` | 内置 `node:test`，所有断言真实执行，不 skip |
| 仓库根 | `python3 docs/work-packages/WP-18/browser-check.py` | Chromium 实机 375/768/1440px，隔离本机服务和合成账号 |
| 仓库根 | `python3 docs/work-packages/WP-18/scope-check.py` | 精确基线/分支、queue owns、他包冲突、文本文件和凭据模式检查 |
| 仓库根 | `git diff --check` | 空白和补丁格式检查 |

完整命令、UTC 时间、cwd、各自退出码及原始输出保存在 `验证输出.txt`。npm 安装首次因默认缓存目录写权限失败；随后只扩大同一默认目录的写权限，再执行原命令成功。没有更换缓存、源、环境或关闭安全策略。

## 最低断言映射

| 要求 | 实际证据 |
| --- | --- |
| 缺母版可加载/启动 | `generator.test.js` 以子进程加载模块，无默认数据目录副作用；`startup.test.js` 启动真实 `node server.js` 并调用健康、订单接口 |
| 配置和订单接口工作 | `http.test.js` 对真实本机 HTTP 服务请求 `/health`、`/config`、`/orders`，核对中文原因、固定金额、账号隔离和空/已有订单 |
| 缺配置明确拒绝 | 直接 `generate` 拒绝 503；缺母版的已付款失败单重试 503，订单和付款原样保留；不会创建订单产物子目录 |
| 槽位与长度 | 唯一编号、正整数上限、非空值、精确键集合、模板识别词、截断/坏 JSON、3 次纠错失败；51 个槽位确实发起 50+1 两批，封面公司名仍受上限校验 |
| 客户隔离和缓存 | 两账号/两订单的相同资料也不能复用复制来的缓存；客户、清单、资料变化及坏缓存触发真实重新适配；每次命中重新验证 |
| 排队与故障 | 文件持久化后读取状态；并发 drain 只执行一单，未支付单不生成；外部 HTTP/网络/导出失败保留订单、释放锁，免费重试不新增付款 |
| 不假生成 | 替身只记录文字 JSON；无真实产物时下载 404；原生导出命令即使“成功返回”但未产出文件也必须失败，清理独立尝试目录 |
| 下载拒绝 | 未登录401，未付款/未完成409，非本人404，畸形 UUID/穿越404；指向虚构文本的文件/目录符号链接404 |
| 幂等与支付关闭 | 持久化 store 重开后同键同资料仍为同单，不同资料409；retry 只留一条事件；完整虚构商户配置仍不能下单、支付或回调，原记录未变 |
| 中文交互与布局 | DOM逻辑测试检查降级、草稿、禁用操作、网络中文错误；Chromium验证三尺寸草稿刷新恢复、无POST、无页面异常、整页无横向溢出、焦点与44px控件 |

所有 HTTP 用例使用临时目录中的合成订单和合成会话文件。支付密码学原测试仍执行，密钥只在测试中现场生成，不连接微信；本包没有删除原有断言。

浏览器使用本仓库已有官网 CSS/JS（只读）和真实方案 API 处理器。只有 `/portal-api/auth/me` 使用合成会话适配；不声称验证了真实邮箱验证码流程。缺品牌 logo 的 404 被作为**预期缺资源**单独报告，没有伪造图片，也没有把资源404算成零控制台错误。
