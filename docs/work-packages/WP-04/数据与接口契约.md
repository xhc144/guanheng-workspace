# WP04 数据与接口契约

起始 integration：`1e36bfce8c13e33f671c95902d23ce2ddabe92ca`。只读静态目录，不新增表、迁移或业务记录。

`catalog.json` 的 `schemaVersion=1`。`sourceBase` 是分支起始基线；当前条目包含WP04自身源码，不能解读为所有条目都存在于该基线。`sourceDigest` 为完整entries规范JSON的SHA-256，提取时间不参与摘要，重复生成结果稳定。API不扫描线上源码、不执行Python、不读取经营明细。

每条条目：

| 字段 | 含义与限制 |
|---|---|
| system | 主线 / 基础版 / Kimi版 / DeepSeek版 |
| kind / method / route | page/PAGE、http/显式HTTP方法、action/ACTION。`view:`/`state:`是基础版状态视图；`#函数`是server action标识，均不是直接HTTP URL。省略框架自动HEAD/OPTIONS、CLI和内联action。 |
| path / line / symbol / sha256 | 仓库相对源码路径、1起始行、AST提取符号和该源文件摘要；不包含绝对工作区路径。 |
| sourceCalls | 该节点最多32项静态调用名称，作为数据访问和行为线索，不证明调用成功。 |
| domain / label / owner | 人工审查后的能力族、中文标题、后续负责包。 |
| decision / rationale | 主线已有 / 移植 / 待用户决定，以及具体边界；已有表示能力族交集，不能推导旧版接口完全等价。不设舍弃类。 |
| primarySources / relatedTests | 已检查存在的主线对应源码和测试路径。测试路径不等于该接口通过。 |
| referenceTests / referenceTestStatus | 参考版测试路径、行、函数与摘要，按明确测试名模式选取的线索；未执行，不证明该接口被覆盖。 |
| runtimeStatus / testStatus | 本次目录条目统一“未逐项运行”；测试字段只标线索。真实目录自身验证由WP04报告单独记录。 |

`GET /api/capabilities` 必须通过当前有效内部管理员会话。返回 metadata、query、total、page、pageSize=25、pageCount、entries。参数 `q` 最多100个UTF-16码元；`system`/`decision`按上述枚举；`page`为1至999999十进制整数，超实际页数夹到末页。空页码、未知参数、重复参数、无效枚举返回中文400，先检查身份再处理参数。q去首尾空白，不作正则或SQL执行。无结果返回空数组与第1/1页。

响应：匿名/失效401，非管理员403，无效筛选400，内部数据库/处理错误500统一中文信息；不回显内部异常、密钥、cookie、token或绝对路径。所有响应 `Cache-Control: private, no-store` 与 `Vary: Cookie`（Next运行时可能追加RSC协商项）。GET读取幂等；HEAD由Next派生，浏览器单独验收；POST等方法由框架405拒绝。

`/capabilities` 通过服务端身份检查；匿名跳转登录，非管理员显示中文拒绝且不渲染目录。GET表单提供系统/决定/中文搜索，分页保留筛选，空状态和错误重置可操作。窄屏使用单列卡片、长路径断行、按钮44px和可见焦点。原生共享导航不在WP04所有权内，直接地址可访问，接入申请见报告。

主线现有SessionUser/getSessionUser/getDb复用，不增加角色或权限定义。目录请求没有业务写入；已有getDb在首次初始化时的schema行为由公共owner维护。无cookie先拒绝，不触发数据库初始化。本域无事务、无迁移、无环境变量、无外部发送。
