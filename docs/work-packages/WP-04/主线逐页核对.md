# 主线逐页、接口与能力边界

先读取主线README、PROJECT_GOAL、AGENTS、页面与接口，再核对三版参考。基于起始 `1e36bfce8c13e33f671c95902d23ce2ddabe92ca`，`systems/project-ops`子树 `f6b26a97bcac879cb479d45f69334fe53c0a6f34`。以下是源码事实，不是运行验收。PROJECT_GOAL历史勾选和DeepSeek FINAL_STATUS的114项声称均未被当成证据。
