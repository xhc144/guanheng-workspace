# 合后严格浏览器失败：证据、最小修补与未确认边界

本次从已合 integration `875fb80613e7626c774d4d7ec3a9eadafb7ae66f` 新建 `wp/24-browser-stability`。不进入G1，不改WP01域文件或任何生产业务代码，不扩依赖/锁文件。最终源码与命令结果见报告最新节和本目录的验证绑定文件。

## 原始事实，不能拼接成绿灯

合后第一轮默认通过、/pms在非管理员鉴权API读取时出现 `ECONNRESET`；第二轮默认等待“运行版本检查通过”标题30000ms超时、/pms通过。两轮整体都退出1。失败发生在受控数据库故障注入之前，不能把它们算作预期500。原工具只留下启动日志，未留下失败页面、请求链、服务退出码或当时版本子进程结果。

原始新日志和当时结论保存在 [postmerge-875fb806](postmerge-875fb806/summary.md)。没有删断言、忽略连接异常、延长原30秒预算或拿不同轮次的通过项拼成整体通过。

## 可以证实的范围

1. 当前安装的Playwright API请求使用持久HTTP agent，默认不重试ECONNRESET；当前Next临时服务实际记录 keepAliveTimeout=5000ms、buffer=1000ms。[观测服务日志](browser-evidence/before/server.log)和[请求链](browser-evidence/before/request-chain.json)保留实际请求/连接编号、时间、版本子进程耗时、页面事件及服务生命周期。
2. [真实HTTP复现](61-real-http-reuse-reproduction.log)：同一真实客户端在持久socket被对端断开时得到传输错误，没有403响应；每次独立连接时保留真实403及响应体。前者两次请求都在socket1，后者分别socket1/2；所有调用maxRetries=0。该受控复现证明连接复用失败机制和隔离措施，不证明历史那一次必定由idle关闭竞态触发。
3. [真实Next负向场景](62-real-runtime-attention.log)：只在临时服务的负向fixture中使pnpm命令不可用，原WP01页面实际显示“运行环境需要处理”，API实际返回attention、pnpm unknown；产品没有伪造版本通过。没有安装替代依赖、更换缓存/源、改生产PATH或改页面源码。
4. [原30秒标题超时复现](66-baseline-heading-timeout-proof.log)：在上述真实页面上，原成功标题等待确实30002ms超时；新验证在约11ms明确断言失败，报告页面实际状态。新逻辑不会把attention视为成功，不点击刷新重试，也不增加预算。
5. 新观测正常运行里，pnpm探测为622–754ms、RSS约189–203MB、loadavg约0.5–0.9；服务直到工具明确cleanup才退出，没有该轮服务崩溃/资源耗尽证据。这不能倒推历史失败时也没有这些因素。

## 仅修改验收边界

- 独立API断言使用 `Connection: close`，明确 `maxRetries:0`；不跨长时间浏览器交互保留API探测socket。真实浏览器自身仍使用正常连接机制，console、pageerror和所有≥400响应严格断言原样保留。服务异常/新的连接错误仍立即失败，不进行请求重试。
- 导航从“只等待成功标题”改为“同一个30000ms总预算内等待目标URL和可见诊断结果，再严格断言结果恰为运行版本检查通过”。已有attention/错误不会等到模糊超时后才退出，也不会变绿。
- 失败时保存实际URL、页面标题/正文和临时截图，以及请求/响应/失败链、子进程exitCode/signal、RSS/线程状态、负载、真实pnpm子进程结果。截图/DB仍只在临时目录，不上传二进制。
- 服务端observer只随临时验证进程加载，不改变timeout、返回值、错误处理或应用行为；收尾前断言服务没有提前退出。会话/配置值不进入新诊断输出；原失败日志只涉及已停止临时服务的合成会话。

## 历史诱因仍未完全确认

原两次失败缺少当时页面与服务状态，无法事后证明默认页面当时是否为attention、是否导航未完成，或连接重置究竟来自idle关闭、当时负载或其他生命周期因素。新增观测未重新捕获相同原始失败；不能声称已排除所有产品问题，也不把观测运行的通过当作根因修复证明。

本PR给出可证实的验收边界修补与后续可诊断性，不给历史诱因编造结论。若未来快照指向WP01真实版本探测/页面缺陷，仍需根协调WP01所有权；本包没有越界修改。根保留G0放行决定权，WP23尚未由本包放行。
