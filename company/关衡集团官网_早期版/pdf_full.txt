后台技术底座：
    基于  Spring Cloud Alibaba 微服务框架，采用  Spring Cloud GateWay  网关，集成  Nacos  注册及配置中
心,采用RestTemplate跨服务访问， 自研参数化二次开发平台，采用插件化指令化服务化分布式架构，开发语言为
Java 11，微服务使用Spring Boot+Javalin框架，采用pf4j插件框架；主要功能插件有单点登录、页面引擎(页面生

据库。
技术中间件：
      分布式缓存Redis、本地缓存H2/Caffeine/STSDB及SqliteDB、消息中间件(RabbitMQ/Kafka)、分布式附件系统
MinIO等。
部署及维护：
      支持Windows/Linux/麒麟等操作系统，私有云、共有云及虚拟化(Docker/K8S)部署;支持Prometheus、Grafana
等，实时监控软件性能和运行状态；采用私有部署Jenkins+Git版本控制系统实现持续集成/持续交付（CI/CD）；采
