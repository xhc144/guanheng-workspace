# 关衡集团企业宣传片 V2 设计与制作规范

## 1. 产品简报

- **目的**：用 60 秒动态演示片建立“关衡 = 进出口关务数字化专业品牌”的第一印象，并引导客户预约产品演示。
- **受众**：制造业、跨国企业与中资境外工厂的管理层、关务负责人、供应链与数字化负责人。
- **核心承诺**：近 30 年只做一件事——帮助进出口企业把关务和合规管清楚。
- **主角**：GTM 全球关务系统及关衡的长期行业积淀。
- **事实依据**：官网公开资料。1997 年起深耕；10000+ 客户；12 个国家；212 个细分行业；100+ 软件著作权；研发技术人员占比 70%+。
- **行动号召**：预约产品演示，400 880 9138。
- **声音原则**：无机器旁白。采用 Mixkit 可商用曲目 `House Vibez` 承载现代科技节奏，电影式转场/落点音效承载镜头反馈。

## 2. 决策表

| 决策项 | 采用 | 不采用 | 原因 |
|---|---|---|---|
| 品牌素材 | 用户提供的横版与竖版关衡集团商标原图 | 猜测、重绘或沿用旧图标 | 保障商标形态正确 |
| 视觉基调 | 白、暖灰、关衡钴蓝，少量深蓝文字 | 旧版深海军蓝 + 金色、全片霓虹 | 更接近商标自身气质，也更现代 |
| 字幕 | 场景内原生大字与信息卡 | 黑色底栏式字幕 | 无旁白时不应模拟传统字幕 |
| 产品画面 | 官网与系统真实截图 | 手绘假系统界面 | 产品证据必须真实 |
| 人声 | 不使用 | 旧式 TTS、过度播音腔 | 用户已明确否定假声音 |
| 音乐 | 稳定的现代科技 House，低音量混音 | 古早企业片音乐、煽情弦乐 | 保持当代、克制、可信 |
| 动效 | 几何线、卡片翻面、数字滚轮、品牌收束 | 弹跳堆叠、无意义光效、游戏 UI 音 | 符合 B2B 专业感 |

## 3. 数据安全姿态

- 仅使用官网已公开的公司介绍、汇总数据、真实系统截图与宣传图片；成片不展示客户名或可识别个人肖像。
- 不展示后台账号、个人手机号、业务明细、客户数据、订单号或任何可识别内部记录。
- 系统截图只做整体界面证据，关键区域不放大到可读敏感字段。
- 不虚构增长数据、客户结果或认证。

## 4. 品牌与视觉令牌

### 色彩

- `brand-blue`: `#176BEF`
- `brand-blue-deep`: `#0757D5`
- `brand-blue-soft`: `#EAF2FF`
- `ink`: `#10233F`
- `muted`: `#64748B`
- `canvas`: `#F7F9FC`
- `white`: `#FFFFFF`
- `line`: `#DCE6F3`

### 字体与排版

- 中文：Noto Sans SC / Microsoft YaHei；不使用仿宋或古典衬线。
- 英文：Inter / Arial，宽字距仅用于小型章节标签。
- 主标题 88–136 px，正文叙事 56–70 px，辅助标签 32–38 px。
- 单屏一句核心信息；辅助信息不超过两行；安全边距 112 px。

### 动效

- 30 fps，确定性渲染。
- 主入场 21f 左右，`bezier(0, 0, 0.2, 1)`。
- 不使用弹跳；只在数字机械锁定、品牌收束时保留极轻的物理刹车。
- 批量动画落定后静止不少于 15f；片尾完整商标静置不少于 45f。
- 全片强冲击不超过 3 次：产品翻面、王牌数据锁定、片尾品牌盖章。

## 9. 声音计划（相对镜头起点）

| 05 | +72 | `impact-deep-whoosh` | 10000+ 整体确认 |
| 08 | +24 | `riser-cine` | 片尾能量收束 |
| 08 | +86 | `impact-deep-whoosh` | 商标标准态落定 |
| 08 | +112 | `sparkle` | 热线与 CTA 收尾 |

- BGM 从第 0 帧淡入，片尾前 120 帧淡出。
- 输出 A：BGM + SFX；输出 B：无 BGM但保留 SFX。
- 音效相对各场景起点书写，禁止散落裸绝对帧。

## 10. QA 关键帧

- `f90`：片头完整商标是否清晰、无白框突兀。
- `f300`：时间线及大字层级。
- `f430`：产品翻面中间态是否无镜像穿帮。
- `f560`：六模块与真实截图是否全部连通且可读。
- `f760`：三项价值卡是否落定、字号足够。
- `f945` / `f1030`：数字滚轮中间态与最终态。
- `f1245`：客户证据墙是否不拥挤。
- `f1450`：核心主张无字幕栏、可一眼读懂。
- `f1660` / `f1760`：片尾商标、CTA 与最终静帧。
