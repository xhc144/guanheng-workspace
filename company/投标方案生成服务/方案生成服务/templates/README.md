# 方案模板（不入库）

本仓库有意不包含客户母版。只有未来另行授权恢复真实生成时，才需要在受控私有部署目录提供配套文件：

- `base-v3.pptx`：48 页关衡 V3.0 技术投标方案母版
- `manifest.json`：由 `template.py` 从母版提取的可替换文本槽位

两者可能含真实客户信息，不得提交到本仓库。本工作包不要求上传它们，也不生成占位母版或占位媒体。
公开版 `generator.js` / `template.py` 中的客户名、地区、产品等识别词已替换为“模板客户”“示例地区A”等占位词；
后续模板变更应先由业务方审阅脱敏内容，并保持清单版本与订单版本一致；不通过修改识别词来掩盖其他客户内容。

缺清单或缺PPT母版时，服务仍可启动并查询已有订单；`/config` 返回中文未配置原因，直接生成和重试明确拒绝。提供密钥也不会让缺母版状态变为可用。支付在本分支始终关闭。

测试的最小虚构清单定义在 `test/helpers.js`，通过构造参数注入，不在本目录创建 `manifest.json`。测试导出器只记录文字 JSON，不产生 PPT/PDF；这不代表真实母版已配置或已验收。
