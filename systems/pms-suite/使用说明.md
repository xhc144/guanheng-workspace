# 综合项目管理系统系列 —— 使用说明（必读）

欢迎使用！这份说明会告诉你**如何打开系统、登录进去、以及遇到问题时怎么解决**。
即使你完全不懂代码，按下面的步骤一步步操作就行。

> 📖 阅读小提示：这份文件是 Markdown 格式。用记事本打开也能正常阅读；
> 如果电脑上有 VS Code / Typora / 浏览器插件等，打开后排版会更清晰。

---

## 一、这是什么系统？

这是一个**项目管理软件**（俗称"系统"），适合中小企业用来管理项目全流程：
项目信息、进度、收款、合同、人员协作等。

一个这样的网站系统通常由两部分组成：

| 组成部分 | 干什么用的 | 用大白话讲 |
|----------|-----------|-----------|
| **前台页面**（前端） | 你在浏览器里看到的界面 | 就像饭店的"菜单"和"前台" |
| **后台服务**（后端） | 处理数据、保存数据的"大脑" | 就像饭店的"厨房"和"仓库" |

所以启动时**要同时把这两部分都启动**，缺一个都用不了。
（启动后你会看到两个黑色命令行窗口，就是这个道理，别关掉它们。）

这个文件夹里一共有 **3 个版本**，功能大致相同，是先后迭代做出来的：

| 版本 | 文件夹名 | 一句话介绍 |
|------|----------|-----------|
| 基础版 | `基础版` | 最简单的版本，主要演示"登录"功能 |
| DeepSeek版 | `DeepSeek版` | **功能最全、最完整，推荐使用这个** |
| Kimi版 | `Kimi版` | 功能也比较全，是另一个版本的实现 |

三个版本互相独立、数据各自分开，**选一个用即可**。

## 二、开始之前：这台电脑需要准备什么？

打开系统需要电脑里装了下面两样东西（**这台电脑已经全部装好了，直接跳到下一节**）：

1. **Python**（版本 3.10 以上）—— 负责后台服务
2. **Node.js**（版本 18 以上）—— 负责前台页面

想确认装没装：按键盘 `Win + R`，输入 `cmd` 回车，在弹出的黑窗口里输入：

```
python --version
node --version
```

能显示出版本号（例如 `Python 3.13.3`、`v24.18.0`）就说明装好了。

另外还需要一个**浏览器**（Edge / Chrome / 360 等都可以）。

## 三、如何启动系统（按版本）

> 💡 **一键启动**：为了方便不熟悉命令行的朋友，本文件夹里已经放了 **3 个"一键启动"文件**，
> 双击即可启动对应版本（不用记任何命令）：
>
> - `一键启动-基础版.bat`
> - `一键启动-DeepSeek版.bat`
> - `一键启动-Kimi版.bat`
>
> 双击时如果弹出"安全警告"，点 **"是" / "仍然运行"** 即可。
> 下面每个版本也附了**手动启动**的命令行方法，供需要时参考。
>
> ℹ️ 这几个一键启动脚本会调用 `start-helper.ps1`（用于正确识别中文文件夹名），
> 请**不要删除或改名** `start-helper.ps1`，否则一键启动会失效。

---

### 3.1 DeepSeek版（推荐，功能最全）

**方法一：双击一键启动（最简单）**
1. 打开总文件夹 `E:\项目\应用项目\综合项目管理系统系列`
2. 双击 **`一键启动-DeepSeek版.bat`**（也可以进 `DeepSeek版` 文件夹双击 `start.bat`）
3. 会弹出两个黑色命令行窗口（一个写 `PMS-Backend`，一个写 `PMS-Frontend`）
4. 等几秒，浏览器会自动打开系统登录页；如果没自动打开，手动访问：
   **`http://127.0.0.1:5182`**
5. 输入账号密码（见第四节）即可登录

**方法二：命令行手动启动（备用）**
1. 按 `Win + R`，输入 `cmd`，回车
2. 复制下面这一整行，粘贴进黑窗口，回车：
   ```
   cd /d "E:\项目\应用项目\综合项目管理系统系列\DeepSeek版" && start.bat
   ```

**启动后对应的地址：**
- 前台页面（浏览器打开）：`http://127.0.0.1:5182`
- 后台服务：`http://127.0.0.1:8102`
- 接口文档（给开发看的）：`http://127.0.0.1:8102/docs`

### 3.2 Kimi版

**方法一：双击一键启动（最简单）**
1. 打开总文件夹 `E:\项目\应用项目\综合项目管理系统系列`
2. 双击 **`一键启动-Kimi版.bat`**
3. 等几秒，浏览器会自动打开登录页；如果没自动打开，手动访问：
   **`http://127.0.0.1:5181`**
4. 输入账号密码（见第四节）即可登录

**方法二：命令行手动启动（备用）**
1. 按 `Win + R`，输入 `cmd`，回车
2. 复制下面这一整行，粘贴进去回车：
   ```
   cd /d "E:\项目\应用项目\综合项目管理系统系列\Kimi版" && powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
   ```
   > 如果想顺便把演示数据重置成初始状态，在命令末尾加上 `-ResetDemo` 再回车。

**启动后对应的地址：**
- 前台页面（浏览器打开）：`http://127.0.0.1:5181`
- 后台服务：`http://127.0.0.1:8101`
- 接口文档：`http://127.0.0.1:8101/docs`

### 3.3 基础版

> 基础版没有"一个文件一键全启动"的脚本，需要**分别启动后台和前台**，
> 所以用命令行操作。请按下面步骤：

1. 按 `Win + R`，输入 `cmd`，回车（打开第一个黑窗口）
2. **第一个窗口**：启动后台服务。复制下面这行，粘贴进去回车：
   ```
   cd /d "E:\项目\应用项目\综合项目管理系统系列\基础版" && powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1
   ```
   （这个窗口**先别关**，它会一直运行后台服务）
3. **再开一个新窗口**（再按一次 `Win + R` → `cmd`）：启动前台页面。复制粘贴回车：
   ```
   cd /d "E:\项目\应用项目\综合项目管理系统系列\基础版" && powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1
   ```
   （这个窗口**也别关**）
4. 打开浏览器，访问：**`http://127.0.0.1:5180`**
5. 输入账号密码（见第四节）即可登录

**启动后对应的地址：**
- 前台页面（浏览器打开）：`http://127.0.0.1:5180`
- 后台服务：`http://127.0.0.1:8100`
- 接口文档：`http://127.0.0.1:8100/docs`

> 当然，基础版你也可以直接双击总文件夹里的 **`一键启动-基础版.bat`**，
> 它会自动帮你开两个窗口并打开浏览器，效果一样。

## 五、如何关闭系统

直接**关掉启动时弹出的那些黑色命令行窗口**即可。
关掉窗口 = 停止服务。下次想用，再按上面的方法启动就行。

> 如果启动时系统自动打开了浏览器页面，关掉窗口后页面就打不开了，这属于正常现象。

## 七、常见问题（FAQ）

**Q1：双击启动文件后，黑窗口一闪而过 / 没反应**
A：多半是电脑缺 Python 或 Node.js。先按第二节确认装好了。
也可以右键启动文件 → **"以管理员身份运行"** 再试一次。

**Q2：提示"端口被占用"（比如 8102 已被占用）**
A：说明之前启动过的系统还没完全关掉，或者别的程序占用了这个端口。
1. 先关掉所有黑色命令行窗口；
2. 再重新启动。
如果还提示被占用，按 `Win + R` 输入 `cmd` 回车，执行：
```
netstat -ano | findstr 8102
```
记下最后一列的数字（这是占用端口的进程号），再执行：
```
taskkill /PID 上面的数字 /F
```

**Q3：浏览器打开 `http://127.0.0.1:5182` 显示"无法访问"**
A：说明后台或前台没启动成功。回到黑窗口看有没有**红色报错文字**。
最常见原因：**启动用的黑窗口被关了**，重新启动一遍即可。

**Q4：登录提示"账号或密码错误"**
A：默认账号 `admin`，密码 `Admin@123456`（注意大小写）。
还不行就试 `admin` / `admin123`；Kimi版可以用 `-ResetDemo` 重置演示数据后再登录。

**Q5：数据存在哪里？会不会丢？**
A：演示数据存放在各版本自己的 `backend\.demo\demo.db` 文件里，**重启系统数据不会丢**。
想恢复成初始演示数据，把该文件删掉再重新启动系统即可（会自动重新生成）。

**Q6：能让同事/朋友在别的电脑上访问吗？**
A：可以，但属于进阶操作：需要让后台监听所有网卡、并在防火墙放行对应端口。
建议找懂网络的人帮忙，或者用 Docker 方式部署。

**Q7：为什么启动后有两个黑窗口？能关掉一个吗？**
A：一个是"后台服务"、一个是"前台页面"，**两个都要开着**。只留一个系统不完整。

**Q8：我不想记命令行，有更简单的办法吗？**
A：有。直接用本文件夹里的 **`一键启动-基础版.bat` / `一键启动-DeepSeek版.bat` / `一键启动-Kimi版.bat`**。
你还可以在桌面给这三个文件建**快捷方式**，以后双击桌面图标就能启动。
