# 设计决策记录

## 1. 技术栈
- **决策**: FastAPI + React + Ant Design + SQLite
- **原因**: 提示词指定默认技术栈，开发效率高，单模块部署简单
- **可逆性**: 可迁移到 PostgreSQL，前端可替换组件库

## 2. 金额类型
- **决策**: 全部使用 Numeric(18,2)，Python Decimal
- **原因**: 禁止浮点数运算，确保财务精度

## 3. 项目进度计算
- **决策**: 基于顶级任务权重计算（非简单任务计数）
- **原因**: 提示词明确要求"应支持任务权重、里程碑权重"
- **公式**: progress = Σ(completed_tasks.weight) / Σ(all_tasks.weight) * 100

## 4. 风险等级判定
- **决策**: 自动计算，概率(1-3) × 影响(1-4)，结果映射等级
- **原因**: 提示词要求"必须显示判定原因，不能成为黑盒"
- **存储**: level_reason 字段记录完整计算过程

## 5. 回款冲销
- **决策**: 逻辑冲销（status=reversed），保留原记录
- **原因**: 提示词要求"财务流水不得随意物理删除，冲销和修改必须留下审计记录"
- **幂等**: 已冲销回款不可再次确认，银行流水号防重

## 6. Excel 导入
- **决策**: 服务器端 openpyxl 解析，排除合计行，逐行错误报告
- **原因**: 提示词要求"识别明细、排除合计行、支持逐行错误提示、部分错误修正"

## 7. 权限模型
- **决策**: 基于角色的权限控制（RBAC），角色层级数值化
- **原因**: 提示词要求"权限必须在服务端验证，支持菜单权限、功能权限和数据范围权限"
- **局限**: 首期未实现数据范围权限（部门隔离），标记为 P1

## 8. 数据库主键
- **决策**: 业务编号（code）与数据库主键（id=uuid12）分离
- **原因**: 提示词要求"业务编号与数据库主键分离"

## 9. 审计日志
- **决策**: AuditLog 表记录所有关键写操作
- **原因**: 提示词要求"操作者、时间、对象、动作、修改前后值"
- **不删除**: 审计日志不可被普通用户篡改
