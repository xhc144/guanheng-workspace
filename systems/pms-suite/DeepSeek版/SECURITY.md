# 安全策略

## 报告漏洞

如发现安全漏洞，请发送邮件至 **security@example.com**（请替换为真实安全邮箱）。不要公开披露。

我们将在 72 小时内确认，30 天内修复。

## 已实施的安全措施

| 措施 | 说明 |
|------|------|
| JWT 认证 | HS256 签名，480 分钟过期 |
| bcrypt 密码哈希 | passlib，自动盐 |
| RBAC 权限控制 | 7 级角色层级（数值比较） |
| 银行流水号幂等 | 重复流水号拒绝（400） |
| 回款双重冲销防护 | 已冲销回款不可再冲销 |
| 文件上传白名单 | 禁止 .exe/.sh/.bat 等 8 种危险扩展名 |
| 路径遍历防护 | 文件名拒绝 `/` `\\` `..` |
| 审计日志 | 关键操作全量记录 |
| CORS 限制 | 仅允许配置的域名 |
